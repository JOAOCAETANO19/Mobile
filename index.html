    Ajustes do jogo

    Backend próprio (yt-dlp) — músicas completas de qualquer fonte. Requer HTTPS se o app estiver rodando em https (veja o README para túnel/deploy).

    Liga o banco de dados online: contas por email + recordes salvos na nuvem. No seu projeto Supabase, vá em Settings → API e copie a Project URL e a anon public key (guia completo no README).
